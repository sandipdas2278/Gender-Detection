# Gender Detection using Deep Learning

## Project Overview
This project focuses on building a Deep Learning model to predict the gender of a person from facial images using Convolutional Neural Networks (CNN).

The system classifies images into:
- Male
- Female

---

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib

---

## Features
- Image preprocessing
- CNN model training
- Gender classification
- Model evaluation
- Prediction on unseen images

---

## Project Workflow
1. Data Collection
2. Image Preprocessing
3. Data Augmentation
4. CNN Model Building
5. Training & Validation
6. Prediction & Evaluation

---

## Dataset
Dataset contains directories with:
- Male images
- Female images
